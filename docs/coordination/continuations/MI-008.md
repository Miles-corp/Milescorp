## Objectif

Connecter un fournisseur (Groq, Gemini, Mistral, OpenAI, Claude…) au minimum de
cliques et d'interactions, p.ex. :

- une seule action pour coller/choisir une clé ;
- si le compte est joignable par un identifiant déjà connecté (p.ex. Google pour
  Gemini), réutiliser ce lien pour réduire les étapes de configuration des
  fournisseurs du même groupe ;
- stockage sûr local (`.env`, jamais dans le dépôt), affichage jamais d'un secret.

## Architecture VALIDÉE (réponses utilisateur du 24/10)

1. **Stockage** : `.env` local gitignoré (choix utilisateur) — clé jamais affichée/journalisée/committée.
2. **Comptes partagés** : réutiliser le fournisseur d'identité déjà connecté (ex. Google pour Gemini) pour raccourcir la configuration des fournisseurs du même groupe ; sinon, étapes réduites.
3. **Portée initiale** : **minimal** — UN fournisseur, puis élargissement après audit indépendant (choix ouvert : Groq candidat naturel, première API du cahier des charges).
4. UI : écran « Réglages » dans la refonte riche (choix utilisateur) de MI-009.

## Prochaine action

Implémentation de l'assistant minimal (`--setup` : choisir fournisseur + coller clé → écriture
`.env` atomique, validation format sans requête réseau), tests de non-exposition des secrets.


## Invariants non négociables

- Clé jamais stockée hors `.env` local (gitignoré) ; jamais journalisée, jamais affichée.
- Aucun envoi de clé vers un service tiers de test sans accord utilisateur.
- Aucun appel payant sans plafond vérifiable et autorisation explicite (charte IA §3).
- Dégradation claire si aucune clé : messages explicites, pas de basculement silencieux.
