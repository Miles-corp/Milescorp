## Objectif

Connecter un fournisseur (Groq, Gemini, Mistral, OpenAI, Claude…) au minimum de
cliques et d'interactions, p.ex. :

- une seule action pour coller/choisir une clé ;
- si le compte est joignable par un identifiant déjà connecté (p.ex. Google pour
  Gemini), réutiliser ce lien pour réduire les étapes de configuration des
  fournisseurs du même groupe ;
- stockage sûr local (`.env`, jamais dans le dépôt), affichage jamais d'un secret.

## Architecture envisagée (à valider après réponses)

1. Assistant de première configuration : `python miles.py --setup` (CLI) +
   écran « Réglages » dans la nouvelle UI web (MI-009).
2. Regroupement des fournisseurs par fournisseur d'identité : Google (Gemini),
   Meta/Mistral, etc. Conjoint pour cacher la complexité aux visiteurs.
3. Choix du modèle automatique en fonction de la tâche (niveau de tâche ≤ budget)、
   conformément à la créativité et à la charte IA (fournisseur plafond strict).

## Invariants non négociables

- Clé jamais stockée hors `.env` local (gitignoré) ; jamais journalisée, jamais affichée.
- Aucun envoi de clé vers un service tiers de test sans accord utilisateur.
- Aucun appel payant sans plafond vérifiable et autorisation explicite (charte IA §3).
- Dégradation claire si aucune clé : messages explicites, pas de basculement silencieux.

## Dépendances

- MI-009 (UI) pour l'écran « Réglages » ; E3 (sessions) pour la sécurité du canal
  web ; S1 (Groq) pour le premier test réel.
